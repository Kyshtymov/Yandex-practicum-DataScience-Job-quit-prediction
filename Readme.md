# Предсказание удовлетворённости работой сотрудников и их ухода из компании

## 📌 Описание проекта

HR-аналитики компании **«Работа с заботой»** помогают бизнесу оптимизировать управление персоналом: бизнес предоставляет данные, а аналитики предлагают, как избежать финансовых потерь и оттока сотрудников. В этом HR-аналитикам помогает машинное обучение, с помощью которого можно быстрее и точнее отвечать на вопросы бизнеса.

**Проблема:** удовлетворённость работой напрямую влияет на отток сотрудников. Внезапные увольнения несут в себе риски для компании, особенно если уходит важный сотрудник.

**Решение:** построены две модели машинного обучения — для предсказания уровня удовлетворённости сотрудника работой и для предсказания ухода сотрудника из компании.

---

## 🎯 Цель исследования

1. **Задача 1:** построить модель, предсказывающую уровень удовлетворённости сотрудника (`job_satisfaction_rate`) на основе данных заказчика.
2. **Задача 2:** построить модель, предсказывающую увольнение сотрудника из компании (`quit`) на основе данных заказчика.

---

## 📂 Данные

Компания предоставила данные с характеристиками сотрудников. Среди признаков:

| Признак | Описание |
|---|---|
| `id` | уникальный идентификатор сотрудника |
| `dept` | отдел, в котором работает сотрудник |
| `level` | уровень занимаемой должности |
| `workload` | уровень загруженности сотрудника |
| `employment_years` | длительность работы в компании (в годах) |
| `last_year_promo` | было ли повышение за последний год |
| `last_year_violations` | нарушал ли сотрудник трудовой договор за последний год |
| `supervisor_evaluation` | оценка качества работы от руководителя |
| `salary` | ежемесячная зарплата сотрудника |
| `job_satisfaction_rate` | уровень удовлетворённости работой (целевой признак задачи 1) |
| `quit` | увольнение сотрудника (целевой признак задачи 2) |

**Файлы:**
- `train_job_satisfaction_rate.csv` — тренировочная выборка для задачи 1
- `train_quit.csv` — тренировочная выборка для задачи 2
- `test_features.csv` — входные признаки тестовой выборки
- `test_target_job_satisfaction_rate.csv` — целевой признак тестовой выборки задачи 1
- `test_target_quit.csv` — целевой признак тестовой выборки задачи 2

## 🔬 Ход исследования

### Задача 1: предсказание уровня удовлетворённости сотрудника

1. **Загрузка данных** — чтение тренировочной и тестовой выборок.
2. **Предобработка данных** — обработка пропусков и дубликатов, изучение типов признаков.
3. **Исследовательский анализ данных** — анализ распределений, выявление аномалий и выбросов, поиск корреляций с целевым признаком.
4. **Подготовка данных** — построение пайплайна с шагами предобработки и кодирования.
5. **Обучение моделей** — обучены как минимум две модели: линейная и дерево решений. Гиперпараметры подобраны для одной из моделей.
6. **Оценка качества** — использована метрика **SMAPE** (Symmetric Mean Absolute Percentage Error). Критерий успеха: SMAPE ≤ 15 на тестовой выборке.
7. **Выводы** — выбрана лучшая модель, проверено её качество.

### Задача 2: предсказание увольнения сотрудника

1. **Загрузка данных** — чтение тренировочной и тестовой выборок.
2. **Предобработка данных** — обработка пропусков и дубликатов.
3. **Исследовательский анализ данных:**
   - составлен портрет «уволившегося сотрудника» (отдел, уровень загруженности, средняя зарплата и т.д.);
   - проверено утверждение о влиянии `job_satisfaction_rate` на увольнение: визуализированы и сравнены распределения признака для ушедших и оставшихся сотрудников.
4. **Добавление нового признака** — `job_satisfaction_rate`, предсказанный лучшей моделью задачи 1, добавлен к входным признакам задачи 2.
5. **Подготовка данных** — пайплайн предобработки и кодирования.
6. **Обучение моделей** — обучены как минимум три модели, для двух подобраны гиперпараметры.
7. **Оценка качества** — метрика **ROC-AUC**. Критерий успеха: ROC-AUC ≥ 0.91 на тестовой выборке.
8. **Выводы** — выбрана лучшая модель, проверено её качество.

## 📊 Результаты

### Задача 1
- Лучшая модель: **DecisionTreeRegressor(max_depth=121, min_samples_split=12,
                                       random_state=42))])**
- SMAPE на тестовой выборке: **13.8** (критерий успеха ≤ 15 — **выполнен**)

### Задача 2
- Лучшая модель: ** DecisionTreeClassifier(max_depth=330, max_features=9,
                                        min_samples_leaf=25,
                                        min_samples_split=37,
                                        random_state=42))])**
- ROC-AUC на тестовой выборке: **0.92** (критерий успеха ≥ 0.91 — **выполнен**)

## 💡 Выводы для бизнеса

1. **Удовлетворённость работой** — ключевой фактор, влияющий на увольнение сотрудников. Модель предсказания `job_satisfaction_rate` позволяет выявлять сотрудников с низкой удовлетворённостью на ранних этапах.
2. **Предсказание увольнений** позволяет HR-отделу вовремя предпринимать контрмеры: проводить беседы, пересматривать условия труда, предлагать повышение или бонусы.
3. **Портрет «уволившегося сотрудника»** помогает выявить проблемные отделы и должности, где отток особенно высок.
4. **Рекомендации:**
   - регулярно проводить опросы удовлетворённости и анализировать их результаты с помощью ML;
   - внедрить систему раннего предупреждения увольнений на основе модели;
   - обратить внимание на отделы и уровни загруженности с наибольшим оттоком;
   - пересмотреть политику повышений и нарушений трудового договора.
